Interactive reference for all endpoints. Point the base URL at your running instance and fire requests directly from this page.

POST /evaluate

Full evaluation with field-level explainability. Returns per-field scores, critical fail reasons, missing fields, unsafe keywords found, and one-line explanations per dimension.

FieldTypeRequiredDescription
request.expected_outputobjectrequiredGround-truth JSON the AI service should produce
request.actual_outputobjectrequiredActual JSON produced by the AI service under evaluation
request.multiple_outputsarrayoptionalRepeated outputs of the same prompt — used only for consistency scoring
config.field_weightsobjectoptionalPer-field importance weights. Unspecified fields default to 1.0
config.critical_fieldsarrayoptionalFields that force FAIL on any mismatch, regardless of score
config.paragraph_thresholdintegeroptionalChar length above which strings use semantic scoring. Default: 60
config.pass_thresholdfloatoptionalMinimum final score (0–100) for PASS verdict. Default: 85.0
config.numeric_deviation_thresholdfloatoptionalFractional deviation above which numeric score → 0 and critical fail fires. Default: 0.30
config.banned_keywordsarrayoptionalCustom safety keyword list. Null or empty → uses built-in default list

Edit the body and click Send Request below.

FieldTypeDescription
scores.correctnessfloat 0–1Weighted field-level accuracy
scores.relevancefloat 0–1Document TF-IDF cosine similarity
scores.completenessfloat 0–1Fraction of expected fields present
scores.consistencyfloat 0–1Avg pairwise similarity across multiple_outputs
scores.safetyfloat 0–11.0 − 0.25 × banned_keyword_hits
scores.final_scorefloat 0–100Weighted sum × 100
verdictstring"PASS" or "FAIL"
verdict_reasonstringOne-line explanation of the verdict
field_resultsarrayPer-field breakdown: field, expected, actual, score, weight, explanation
critical_failsarrayTriggered override rules: rule, field, detail
missing_fieldsarrayExpected fields absent from actual output
unsafe_keywords_foundarrayBanned keywords detected
explanationsobjectOne-line explanation per scoring dimension

        /evaluate/batch
      

      

        Evaluate up to 100 request-config pairs in a single HTTP call. Each item is evaluated independently.
        Errors in individual items are returned as BatchResultItem.error rather than failing the whole batch.
